# anna-vihar-simple-logic-page
This is a login page for practice, just an example using HTML,CSS &amp; JS
A login and signup page for Anna Vihar – Digital Agri Hub, with a flip-card animation that switches between the Log In and Register forms.


1.Flip animation between Login and Register panels
2.Custom logo and green colour theme
Built with:
HTML
CSS
JavaScript
Font Awesome icons
Montserrat font
How to run
Download or clone this repository
Open index.html in your browser
Note

This is a front-end demo only. It does not check real accounts or store any data.
